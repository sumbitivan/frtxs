===========================================
  БЫСТРАЯ ЗАГРУЗКА НА GITHUB
===========================================

ВЫПОЛНИТЕ ЭТИ КОМАНДЫ В POWERSHELL:

1. Перейдите в папку проекта:
   cd f:\CursorProjects\crypto-exchange-miniapp

2. Удалите старую папку .git (если есть):
   Remove-Item -Recurse -Force .git

3. Инициализируйте git:
   git init

4. Настройте пользователя:
   git config user.name "sumbitivan"
   git config user.email "syedwang789@gmail.com"

5. Добавьте все файлы:
   git add .

6. Создайте коммит:
   git commit -m "Initial commit"

7. Создайте репозиторий на GitHub:
   - Откройте https://github.com/new
   - Название: crypto-exchange-miniapp
   - НЕ добавляйте README, .gitignore, лицензию
   - Нажмите Create repository

8. Подключите к GitHub (замените YOUR_USERNAME):
   git remote add origin https://github.com/YOUR_USERNAME/crypto-exchange-miniapp.git
   git branch -M main
   git push -u origin main

9. Включите GitHub Pages:
   - Settings → Pages
   - Source: main branch, / (root)
   - Сохраните

10. URL вашего приложения:
    https://YOUR_USERNAME.github.io/crypto-exchange-miniapp/standalone.html

11. Настройте в BotFather:
    - /newapp
    - URL: https://YOUR_USERNAME.github.io/crypto-exchange-miniapp/standalone.html
