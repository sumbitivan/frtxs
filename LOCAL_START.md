# 🚀 Локальный запуск

## ✅ Что запущено:

1. **HTTP сервер** - работает на `http://localhost:8080/`
2. **Telegram бот** - запущен и готов к работе

## 📱 Как использовать:

### Вариант 1: Тестирование в браузере

1. Откройте в браузере: **http://localhost:8080/test.html**
2. Вы увидите Mini App с моковыми данными Telegram API
3. Можете протестировать весь функционал

### Вариант 2: Тестирование в Telegram

1. Откройте вашего бота в Telegram
2. Отправьте команду `/start`
3. Нажмите кнопку "💱 Обменять валюту"
4. Mini App откроется (нужно указать правильный URL в BotFather)

## 🔧 Ручной запуск (если нужно перезапустить):

### Запуск сервера:
```powershell
cd f:\CursorProjects\crypto-exchange-miniapp
node server.js
```

### Запуск бота (в другом окне):
```powershell
cd f:\CursorProjects\crypto-exchange-miniapp
node bot-simple.js
```

## 📝 Доступные URL:

- **Главная страница**: http://localhost:8080/
- **Тестовая страница**: http://localhost:8080/test.html
- **Стили**: http://localhost:8080/styles.css
- **Скрипт**: http://localhost:8080/app.js

## ⏹️ Остановка:

- Закройте окна PowerShell с сервером и ботом
- Или нажмите `Ctrl+C` в каждом окне

## 🔍 Проверка работы:

1. Откройте http://localhost:8080/test.html
2. Вы должны увидеть интерфейс обмена валют
3. Попробуйте:
   - Изменить направление обмена
   - Ввести сумму
   - Проверить автоматический расчет

## 💡 Примечания:

- Для работы в Telegram нужно развернуть Mini App на HTTPS
- Локальный сервер работает только на вашем компьютере
- Бот работает и может принимать команды из Telegram
