# 💱 Telegram Mini App - Обмен валют (USDT/RUB)

Мини-приложение для Telegram, предназначенное для обмена валют.

## 🚀 Функционал

- **Главная страница** с баннером курсов валют
  - Колонка покупки USDT за RUB
  - Колонка продажи USDT за RUB
  - Автоматическое обновление курсов каждую минуту из CurrencyAPI

- **Форма обмена валюты**
  - Выбор направления обмена (покупка/продажа USDT)
  - Ввод суммы с автоматическим расчетом итоговой суммы
  - Заполнение контактной информации
  - Отправка заявки

- **Настройки**
  - 🌓 Переключение темы (светлая/темная)
  - 🌍 Выбор языка (Русский, Английский, Китайский)
  - Настройки сохраняются в localStorage

- **Информационные разделы**
  - ℹ️ О нас
  - 🔒 Безопасность
  - 💬 Поддержка 24/7 
  - ⚙️ Настройки

- **Интеграция с Telegram WebApp API**
  - Адаптивный дизайн под Telegram
  - Использование темы Telegram
  - Кнопка "Назад" в нативном интерфейсе

## 🛠 Установка и запуск

### Локальная разработка

1. Клонируйте репозиторий
2. Откройте `standalone.html` в браузере для предпросмотра
3. Для полноценного тестирования нужен Telegram бот

### Развертывание на GitHub Pages

1. Загрузите файлы на GitHub
2. Включите GitHub Pages в настройках репозитория
3. Выберите папку с файлами или корневую папку
4. Ваше приложение будет доступно по адресу: `https://username.github.io/repository-name/`

### Развертывание на других платформах

- **Netlify**: Перетащите папку в Netlify
- **Vercel**: Импортируйте репозиторий
- **Любой хостинг**: Загрузите файлы через FTP

## 🤖 Настройка Telegram бота

### 1. Создание бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните токен бота

### 2. Настройка Mini App

1. Отправьте команду `/newapp` в BotFather
2. Выберите вашего бота
3. Укажите название приложения
4. Добавьте описание
5. Загрузите иконку (512x512px)
6. Укажите URL вашего приложения (например: `https://yourusername.github.io/crypto-exchange-miniapp/`)
7. Сохраните полученный URL для мини-приложения

### 3. Запуск бота

```bash
# Установите зависимости (если используете bot-example.js)
npm install

# Запустите простого бота (без зависимостей)
node bot-simple.js

# Или запустите бота с зависимостями
npm start
```

## 📡 API курсов валют

Приложение использует ЦБ РФ через JSONP (обходит CORS в Telegram WebView):
`https://www.cbr-xml-daily.ru/daily_jsonp.js`

- Обновление: каждую минуту
